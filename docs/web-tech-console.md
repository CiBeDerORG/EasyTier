# Web 控制台视觉升级

本次在 `feat/web-tech-console` 分支中统一登录、注册、仪表盘、设备、网络、ACL、地图、服务及弹窗的视觉和布局。网络地图、节点空间与服务配置的功能说明仍见 [网络地图与服务导航](network-map-services.md)。

## 视觉体系

- 深色使用深蓝背景和青色主操作；浅色使用灰蓝背景、白色面板和深青色文字。基础色与 PrimeVue 控件定义位于 `frontend/src/theme.ts`，页面、抽屉和弹窗共享的样式位于 `frontend/src/console.css`。
- 左侧菜单可收起，手机使用抽屉；顶栏提供设备接入、通知、主题、语言和账户操作。底部显示当前控制台模式，模式来自实际接口。
- 仪表盘增加网络主视觉、地图和服务入口、设备在线占比。设备列表增加在线与离线筛选；网络列表展示成员规模和在线进度。所有统计来自当前接口数据。
- 网络详情将身份、安全与连接设置分区，危险操作单独排列；设备详情与 ACL 使用一致的分组和状态层级。
- 服务编辑抽屉提前展示导航开关，底部固定保存与取消按钮。保存沿用原表单验证与请求。
- 支持中英文、浅深主题、手机布局、键盘焦点与减少动态效果设置。

以上源码路径均相对于 `easytier-web/`。

## 图片与动效

`frontend/src/assets/console/network-atmosphere.webp` 为本次生成的装饰图片，1672 × 941，约 91 KB，用于登录品牌区与仪表盘主视觉。它不表达实时网络状态；实时 3D 地球和户型继续使用现有的独立渲染组件。

本次未新增运行时依赖、外部图片请求或持续运行的背景 WebGL。页面入场和悬停动效保持短暂，减少动态效果设置会关闭相关动画。

## 表单反馈

登录、注册与修改密码在提交时阻止重复请求，失败时保留输入并显示错误。验证码可以手动刷新；单点登录配置不可用时，账户密码登录继续可用。沿用现有认证接口与密码编码协议。
