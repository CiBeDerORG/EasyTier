# 网络地图与服务导航

这组功能用于 EasyTier Web 中央管理模式。外部 Webhook Console 模式沿用原有设备管理入口，不展示或开放中央网络地图、服务管理接口。

## 使用流程

1. 在「网络节点」中接入 EasyTier 节点，填写节点属性和经纬度。地图使用同一批注册节点，不需要先在下方「网络」菜单创建集中式网络。
2. 打开「网络地图」，选择节点查看详情；未填写坐标的节点仍在「待定位」列表，点击「编辑节点」可补充位置。
3. 在「设备管理」维护该节点的网关及下挂设备，地图直接展示已有资产关系。户型与拓扑是本地视图选项，房间仅作示意，不维护另一份地图设备。
4. 点击地球上的节点查看详情，进入「节点空间」旋转查看设备关系；点击线路查看连接信息。未填写坐标的节点仍保留在列表中。
5. 在设备下添加服务，填写 HTTP/HTTPS 地址并开启「显示在服务导航」。服务管理与导航使用这条设备服务记录；独立「服务导航」菜单位于「仪表盘」上方。
6. 点击导航卡片直接访问服务；卡片菜单可以编辑、定位到地图或移出导航。移出导航保留服务配置，彻底删除在「服务管理」中操作。
7. 桌面侧栏底部可收起菜单，浏览器会记住状态；手机使用顶部菜单按钮。

## 数据含义

- 地球是可交互的 Three.js WebGL 球体，使用随前端打包的 NASA 地球纹理，无需外部地图密钥。纹理是静态底图；节点、线路与流量是独立图层。来源见 [纹理说明](../easytier-web/frontend/src/assets/map/README.md)。
- 缩放按离地高度连续变化，可从全球视角进入近景。滚轮、触屏和加减按钮采用同一规则；选择节点保留当前高度，重置按钮返回全局视角。
- 行政图层使用离线 Natural Earth 国家与一级行政区数据，远景显示国家，放大后显示省、州等边界和名称，近景提供视野中心所属行政区。名称随视角即时调整，边界数据为固定来源版本，不是实时行政变更或街道底图。来源与更新方法见 [行政数据说明](../easytier-web/frontend/src/assets/map/administrative-data.md)。
- 节点以小圆点显示，点击范围独立于圆点尺寸。相近节点在屏幕上展开并用引线连接真实位置；真实经纬度不会因展开而改变。同址链路仍保留，邻近线路采用错开绘制，重叠位置提供连接选择入口。
- 经纬度来自网络节点属性，支持已有地图选点与位置编辑。真实运行连接按注册机器及其实例关联，无法可靠匹配的远端节点不会生成虚构连线。
- 直连来自节点的 peer 连接；中继路径根据路由下一跳逐段校验。弧线表达逻辑连接，不代表实际光纤地理路径。
- 流量速率由累计字节的相邻采样差分计算，同一连接不会将两端报告重复相加；只有检测到传输活动时播放流动粒子。默认约每 15 秒更新一次。首次采样、计数重置、离线、请求失败或页面隐藏时不制造流量动画。
- 户型是固定的 3D 示意模板，设备归属来自资产网关关系，房间摆放仅为便于观看。它不是户型扫描，也不自动发现或监测局域网设备；关系线表示配置归属。
- 网关和其自身设备合并为一个可选对象。只有一个有效网关且存在自身资产时，由该对象承担站点中心展示；多个网关分别保留，通过抽象站点连接点组织关系。选择、服务和编辑仍使用原资产 ID。
- 服务状态显示「未检测」。配置地址不会触发服务器主动探测；浏览器直接访问目标地址，访问私网地址需要当前设备已有相应网络连通性。
- 浏览器不支持 WebGL 时仍可通过节点列表编辑信息、管理关联设备和访问服务。遵循减少动态效果设置，也可暂停动画。

## 数据来源与持久化

节点位置、资产设备及服务沿用各自原有记录和账号权限。导航开关通过独立 PATCH 修改，不覆盖其他服务字段；清除访问 URL 会关闭该服务的导航入口。地图和服务链接可定位到原设备所在分页并展开其服务。

旧独立地图配置和旧服务记录保留在原表，当前页面不再读写它们，也不会自动复制或删除。修改集中式网络列表不会改写注册节点和资产目录。

主要读取与修改接口（沿用登录会话和资产作用域）：

| 方法 | 路径 | 用途 |
| --- | --- | --- |
| GET | `/api/v1/machines` | 注册网络节点及位置 |
| GET | `/api/v1/assets/gateway-groups`、`/api/v1/assets/devices` | 资产网关和设备 |
| GET | `/api/v1/assets/services` | 所选账号的设备服务目录 |
| POST | `/api/v1/assets/devices/{id}/services` | 在设备下新增服务 |
| PUT / DELETE | `/api/v1/assets/services/{id}` | 修改 / 删除原设备服务 |
| PATCH | `/api/v1/assets/services/{id}/navigation` | 更新导航显示状态 |

## 开发验证

前端构建需要仓库原有的 `protoc`。安装依赖后可在仓库根目录执行：

```sh
pnpm --dir easytier-web/frontend build
pnpm --dir easytier-web/frontend test:unit
pnpm --dir easytier-web/frontend test:network-space
cargo test -p easytier-web --locked
```

`test:browser` 同时执行原有控制台与新增地图/服务浏览器测试。浏览器测试需要 Playwright Chromium；使用系统 Chromium 时可设置 `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`。设置 `WEB_SCREENSHOT_DIR` 可保存新增界面的桌面与手机截图。

浏览器套件使用明确标注的测试网络和模拟 API；它验证交互、请求与异常流程，不替代真实网络设备的数据面端到端测试。拓扑计算测试覆盖中继逐跳验证、流量去重与重置、过期数据、无法匹配的远端节点和日期变更线；后端测试覆盖持久化、权限、引用约束及配置冲突。
