# Earth textures

These textures are bundled with the frontend, so opening the network map does not
contact an external map provider or require an API key.

- `earth-blue-marble.jpg`: NASA Blue Marble Earth imagery, distributed by the
  [three-globe examples](https://github.com/vasturiano/three-globe/blob/master/example/img/earth-blue-marble.jpg).
- `earth-night.jpg`: NASA Earth at Night imagery, distributed by the
  [three-globe examples](https://github.com/vasturiano/three-globe/blob/master/example/img/earth-night.jpg).

Source repository: [three-globe](https://github.com/vasturiano/three-globe), MIT.
NASA imagery is used for geographic visualization under the
[NASA imagery usage guidelines](https://www.nasa.gov/nasa-brand-center/images-and-media/).
The imagery is a static Earth basemap, not live satellite imagery. Network nodes,
links, and traffic are separate data-driven layers. Link arcs express logical
network connections and do not claim to trace physical fiber routes.
