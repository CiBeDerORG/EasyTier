## 明细的使用方式

每份明细包含：任务编号、关联需求/验收、前置依赖、允许写入范围、输入输出契约、执行步骤、验收清单、交付清单、阻塞/交接和执行记录。

1. 阅读 [全局协作规则](../../README.md)、计划及要认领的任务；以明细中的实际依赖判断就绪情况。
2. 由协调者登记负责人和状态。未来新增文件在 `write_scope` 中表示计划范围，不代表已经实现。
3. 只修改本任务拥有的业务文件；不同 Agent 按独立模块并行，共享入口按计划串行交接。契约或范围变化先同步任务记录。
4. 完成针对性验证并交付证据，再由下游接线/联调；最终 WUM-010 和 WUM-011 分别验证跨端行为与升级交付。

本目录记录本轮已处理的11项任务。任务明细与看板均为 `done`，验收勾选已完成；历史规划和执行记录保留，不代表仍有待办。后续新增需求须另行建项，不能据本轮完成状态推定其已实施。
