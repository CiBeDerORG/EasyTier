# WUM-010：真实前后端联调

需求：[Web 用户管理](../../../docs/requirements/web-user-management.md)。计划：[PLAN-WUM](../../plan/web-user-management.md)。[返回看板](../README.md)。

## 目标与边界

使用真实后端、数据库和浏览器验证跨端账号管理，集中接入用户管理测试执行入口。现有 test:browser/test:e2e 只指定已有文件，新增测试必须实际被运行。

## 输入与输出契约

输入 WUM-006 管理 API、WUM-009 Web 流程、各模块测试记录和 WUM-001 部署契约；准备隔离测试库、管理员/普通用户与多会话。输出可复现联调结果与验收映射，交付 WUM-011。

## 执行步骤

1. 核对前后端交付使用同一契约，准备隔离数据库、至少管理员与普通用户、多浏览器会话，以及适用身份模式的测试配置。
2. 先通过真实 HTTP 检查授权、账号状态、并发与会话规则，再让浏览器完成列表、创建、停用、重置、角色、审计和错误恢复流程。
3. 为分页筛选及独立撤销会话设置专门场景，将新增测试接入实际执行入口，核对运行结果确实包含新增用例。
4. 按 UA 编号整理证据；失败回派对应模块任务，等待修复交接后重验受影响场景，再将通过结果交给升级验收。

## 实施与验收

- [ ] 覆盖关联 UA 场景：真实权限、创建与冲突、停用/恢复、改密、角色并发、会话撤销、注册策略、审计及跨站写入策略。
- [ ] 独立检查 UM-02 的服务端搜索、角色/状态筛选、稳定分页、空结果和历史未知值；不能仅验证列表读取成功。
- [ ] 独立检查 UM-07：保持密码、角色和访问状态不变，主动撤销全部 Web 会话；旧会话失效，重新登录可用。
- [ ] 按适用身份模式验证本地/OIDC/外部映射；未执行或不适用需具体说明，不用 mock 结果替代。
- [ ] 验证组件反馈与服务器结果一致，设备/网络行为遵守仅停用控制台的范围；不输出真实凭据或哈希。
- [ ] 接入可运行的测试命令并运行；单元、mock、HTTP、浏览器结果分别报告。
- [ ] 所有关联运行时验收有结论，未解决缺陷不标为通过；旧库升级/恢复整体结论由 WUM-011 完成。
