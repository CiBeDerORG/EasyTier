# WUM-003：账号存储与数据库迁移

需求：[Web 用户管理](../../../docs/requirements/web-user-management.md)。计划：[PLAN-WUM](../../plan/web-user-management.md)。[返回看板](../README.md)。

## 目标与边界

按契约扩展账号状态、会话版本、必要时间、身份绑定和审计存储；提供可供认证和业务服务独立消费的 DB 接口。新增迁移与实体注册由本任务统一负责，不修改已发布迁移。

## 输入与输出契约

输入为 WUM-001 的数据/状态/事务契约。输出为迁移后的模型、查询/修改接口、事务调用方式和测试夹具。业务事务策略由 WUM-005 负责，本项提供事务所需原子基础，避免两层各实现一套规则。

## 执行步骤

1. 对照已交付契约整理字段、默认值/空值、约束和事务接口，核对现有迁移顺序及旧数据关系；有契约缺口先回交 WUM-001。
2. 新增 migration 与实体，统一完成注册；保留历史未知信息，提供约定的列表查询和事务存储接口。
3. 在测试数据库中分别建立旧库和新库路径，执行迁移、冲突、回滚及必要原子操作验证，确认测试实际调用新增迁移。
4. 编译相关模块并整理接口使用说明、测试夹具和升级结果，交付认证与业务服务任务；不代写其业务策略。

## 实施与验收

- [ ] 旧用户 ID、用户名、密码哈希、组关系、资源归属保持；历史时间与身份来源未知时不造假。
- [ ] 支持列表稳定分页、状态与角色查询、会话版本、身份唯一约束和审计写入；不返回包含密码哈希的公开 DTO。
- [ ] 明确并发角色变更与最后管理员保护所需的事务保证，供 WUM-005 使用；提供必要的幂等关系操作。
- [ ] 测试旧库升级、新库、冲突/回滚与未知值；新增实体和 migration 已注册并参与实际执行。

## 交付清单

- 新 migration、实体、注册变更及数据库接口，说明每个接口的事务与错误语义。
- 旧库/新库测试夹具和实际验证记录，包含保留字段、历史未知值及失败回滚结果。
- 给 WUM-004/005 的调用示例与接口缺口反馈入口，明确后续迁移仍由本任务所有者协调。

## 阻塞与交接
