## 2. 两层入口的目标范围

|入口|位置与身份提示|操作目标|
|---|---|---|
|全局浮球|脱离内容布局，叠在页面右侧的页面级浮球；默认仅主按钮及“已选 N 台”小徽标，展开时用短标签补充账号与范围|普通模式沿用工作台已选目标，点击批量动作时固定本次目标集；不直接照搬 EasyADB“所有活动画面”的范围|
|单机浮球|叠在本机视频容器内的边缘；默认仅主按钮及必要的“本机”小徽标，展开时显示设备名或可区分的短标识|仅当前实体设备，永不广播；即使这台设备被设为主控也不改变单机按钮含义；点击单机按钮不自动勾选设备，也不改变全局选择集|
|主控同步期间的全局浮球|醒目显示“同步中 · 固定 N 台”及主控身份；列表选择变化提示“尚未应用到本次同步”|使用创建同步会话时确定的目标；全局返回、主页、最近任务、文字等也沿用该固定目标集|

两层浮球均不占据页面或卡片的布局宽度，不预留操作列，不设置固定竖栏或全高背景面板。展开和收起不改变视频宽度、原始比例、卡片列数及周围内容位置。

“已选数量”“本次同步目标数量”“实际就绪数量”分别展示，不把某台失联后少掉的数量当成用户主动移除了它。管理员跨账号时先选择一个目标账号；切换账号不沿用上一账号的选择或控制状态。

用户想改变同步目标时，先停止当前同步，再重新选择并启动。新增勾选、取消勾选、筛选或翻页都不能静默修改正在执行的目标集。失效目标必须逐台标明原因，不通过悄悄跳过设备来改变操作范围。

## 3. 建议动作编排

主按钮点击展开后，常用动作保持固定顺序：**返回 → 主页 → 最近任务 → 文字输入 → 唤醒 → 更多**。动作以主按钮周围独立的圆形图标展开，可以沿视频边缘紧凑分布，不用贯穿卡片高度的底板将其组合成侧边栏。基础图标复用项目现有 PrimeIcons，统一线条、尺寸和状态，保留文字提示与可访问名称；借鉴 EasyADB 的动作组织，不把其 Unicode 字符直接搬入产品。业务含义按本需求明确。

|动作|全局|单机|边界|
|---|---|---|---|
|返回、主页、最近任务|发送到本次明确目标集|仅本机|写入控制命令，必须拥有相应控制权|
|文字输入|弹出批量文字面板并显示目标数量|弹出本机文字面板|明确点击发送；不全局捕获键盘；中文能力按实际设备适配结果显示|
|唤醒|对明确目标逐台请求唤醒|仅本机|不是解锁，不推断密码或自动输入已存凭据|
|更多 → 重连画面|对明确目标逐台重建观看会话|仅重建本机观看会话|不得变更目标 IP、自动切换线路或隐式扩大范围；不是后台自动重连|
|更多 → 停止画面|明确列出即将停止观看的设备|只停止本机观看|与停止同步、取消脚本任务是不同动作，不共用含糊的“停止”文案|
|更多 → 日志|打开本次范围的逐设备结果|打开本机日志|可在设备不可写或任务占用时使用|
|全屏/退出全屏|不提供|本机展示动作|不取得控制权，不改变目标；全屏时隐藏全局菜单|
|录制操作|不提供|进入本机录制流程|新增设计，非 EasyADB 已有功能；录制前说明设备及记录范围，并与同步/脚本占用互斥|

全屏建议作为单机菜单的独立按钮，录制操作放在单机“更多”内，避免常用导航拥挤。脚本编辑和批量执行继续由工作台/脚本页面的明确流程承载，不因为出现悬浮栏就自动新增一套隐藏任务入口。

**立即停止同步**在群控工作区始终可见，不能藏进“更多”或随浮球菜单收起消失。脚本运行时同样保留明确的任务取消入口；停止画面不能冒充已经取消后台任务。

## 4. 控制占用与禁用规则

- 普通观看不自动进入同步控制。菜单是否显示、画面是否在线、设备是否可写是不同状态；有画面不代表点击或文本注入已获允许。
- 单机按钮永远只控制本机。处于主控同步或脚本运行占用中的设备，单机写入命令及新录制入口禁用，提示“先停止同步”或“先停止当前任务”；不能点击后偷偷退出原任务或改变控制权。
- 占用期间保留观看、日志、全屏。重连/停止画面若会打断当前控制会话也禁用并解释原因；正式架构若能完全分离观看订阅，再明确其只影响观看的行为，不在产品稿中假定已实现。
- 从主控视频发出的同步点击、滑动属于明确的群控流程；它不是单机悬浮菜单动作。主控身份不能把单机返回键、单机输入框等悄悄变成广播操作。
- 全局导航在同步中只能使用同步会话固定目标；存在脚本占用时不能另发手工输入。新同步、录制、试跑和脚本执行须检查所选设备占用，未释放前不启动冲突操作。
- 每项动作按能力单独判断。例如某台能看不能触控、能点击不能输入某种文字、或缺少唤醒能力，页面分别提示；不能仅按“手机在线”统一启用全部按钮。
- 执行前显示不可用目标和原因。普通批量命令可以按 R06 的流程，由用户显式移除不可用目标，显示修改后的范围并确认后继续；页面不能自动取消勾选或静默跳过。同步期间保持会话固定目标，目标失效保留该台的阻断/失败结果；若要更改范围，须先停止同步，再重新选择并开始。
- 状态区分请求中、命令已发送、设备失败和结果待确认；收到发送成功不能冒充手机页面或业务操作成功。

## 5. 展开、输入与布局

- 默认只显示浮球主按钮及小范围徽标，点击主按钮展开独立圆形动作图标；再次点击、点击菜单外部或按 Esc 收起。收起后移除展开图标对画面的遮挡，仅保留小浮球，恢复观看空间。收起菜单只改变界面，不停止正在运行的同步或脚本。
- 不要求 hover 才能发现按钮。可用 hover/focus 提示名称，但手机触屏与键盘同样能打开菜单；禁用原因可通过相邻提示访问。
- 文字输入框获得焦点期间不按 EasyADB 的5秒计时自动收起，避免输入被打断。第一版建议统一由显式关闭、外部点击或 Esc 收起，不引入自动隐藏计时。
- 收起时以紧凑徽标显示全局目标数或本机身份，不能留下两个作用范围无法区分的相同图标，也不能把范围文字拉成常驻长面板。全局与单机通过层级、位置、范围文字及视觉样式共同区分，不能仅靠颜色。
- 本轮不增加拖拽、自定义位置保存或自动吸边，避免补入用户没有要求的操作方式。
- 全局浮球叠在页面上，单机浮球叠在各自视频容器内。展开可能临时遮住少量画面，通过靠边的紧凑排列和手动收起处理；不为操作区留白，不缩窄视频，不改变手机比例或卡片列数，也不改成卡片外侧固定面板、全高背景板或布局占位。
- 建议交互命中区域至少44×44 CSS px；浮球与展开图标在可见边界内保留点击余量，横屏、窄屏与全屏时不能把动作裁掉。这里的点击余量属于叠加控件的位置约束，不是为其预留页面或视频宽度。
- 悬浮按钮、文字面板、展开区域和收起用的遮罩不能穿透成手机触摸。外部点击用于收起菜单时，应先消费该次事件，避免一次点击同时关闭菜单和触发手机操作。
- 全屏只显示叠在本机画面上的本机浮球，全局浮球隐藏，画面不因控件出现而缩窄。若已有手动同步会话，全屏顶层仍保留明确的同步状态和独立“立即停止同步”入口；这是会话操作，不属于本机菜单，不随菜单收起或全局菜单隐藏消失。本机菜单保持单机含义和占用禁用规则。

## 6. 设计评审要点

本节是后续评审/验证清单，不代表已经执行。

1. 页面选中3台时，全局菜单明确显示3台；单机菜单标明本机且只对本机生效。
2. 同步期间再勾选第4台，当前会话仍为原3台；新选择不混入全局导航命令。
3. 主控设备单机菜单不会广播；同步或脚本占用时单机写入禁用，日志与全屏仍可用。
4. 一台目标失联时保留原目标数量并展示问题，不悄悄变成另一个目标集。
5. 编辑长文本期间菜单不因5秒无操作自行关闭；按钮、外部点击、Esc行为一致。
6. 单机全屏后全局菜单隐藏；本机菜单、当前模式、必要的停止同步入口仍可找到。
7. 点击悬浮图标、输入框或外部收起区域不会在手机里产生多余点击。
8. 停止画面、停止同步、取消脚本三种结果清楚区分；录制入口明确是待实现功能。
9. 默认只有主浮球及小徽标；展开为独立圆形图标，页面及卡片都没有固定工具列、全高底板或新增留白。
10. 展开与收起前后手机画面宽度、比例、卡片列数保持一致；临时遮挡可通过收起消除，浮球交互不穿透成手机操作。
