# P02 本轮实施计划

基于f951e054的现有自动化菜单/规划页推进，当前实现以R10接口为准。R01–R09作为需求与架构依据，不将早期Go/WSS规划继续当作首选。

1. 冻结资产目标、有限步骤、会话/任务协议；创建T01–T06不重叠写入范围。
2. 主服务复用资产/账号持久化任务；执行器实现真实ADB、WebRTC和有界动作；前端同时实现手机墙与脚本记录。
3. root统一接入Rust模块、迁移及依赖，审查端到端数据契约、授权撤销、关闭/取消/重启等分支。
4. 更新任务看板及测试报告，代码成型后一次性提示建议测试范围；未授权不执行测试，也不部署/提交/push。

本轮首版采用主服务认证代理控制/信令，浏览器不持执行器密钥。独立SSE若未提供则页面明确使用手动结果查询；不会用轮询伪装事件推送。后续真机测试再收敛容量、画质、ICE/TURN部署及中文输入兼容性。
