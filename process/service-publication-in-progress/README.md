# 服务公开与公网端口映射

## 当前进度

- 2026-10-23：前后端与迁移已实现，完成手工源码交叉审阅；运行验证未执行。
- 新增、编辑服务时可选择是否公开；公开配置选择同账号公网服务器的运行网络。
- 服务与公开映射通过同一个保存请求写入；取消公开和删除服务时清理其拥有的映射。
- 设备组网 IP 变更会同步更新已公开映射的目标地址；服务列表展示公开配置摘要。
- 补齐 IPv6 地址从持久配置到运行回读的转换，兼容裸地址与方括号形式。
- 继续处于调试模式：本轮不执行测试、构建、类型检查、lint 或手动触发 CI。

## 关键约束

- 目标地址由后端读取设备当前组网 IP，前端只读；协议继承服务 TCP/UDP。
- 只修改可由 Web 管理的已保存运行网络，不接管中心或本地配置。
- 保留其他服务及手工配置的转发规则；使用独立记录跟踪本服务写入的完整规则及目标配置身份。
- 配置保存与运行生效分开表述，使用现有运行配置协调机制应用端口映射。
- 若映射被外部改动、配置归属改变或目标配置被替换，返回明确冲突或要求重新绑定，不隐式覆盖新配置。

## 分工与入口

- 前端负责人：服务表单、公开弹窗、服务列表、前端类型/API/中英文文案。
- 运行接口负责人：运行网络候选、运行状态证明、配置变更通知。
- 存储负责人：迁移、公开记录、同事务映射写入、删除清理与地址同步。
- 主线程：接口接线、契约/记录、交叉审阅与中文提交推送。
