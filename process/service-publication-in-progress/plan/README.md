# 实现计划

## 存储

- 新增服务公开表，记录目标配置身份、绑定参数和完整已写入转发规则。
- 扩展服务输入校验与响应；保持原请求兼容性和创建幂等语义。
- 在服务创建、更新、删除以及设备删除、地址变更事务中维护映射。
- 只更改目标网络的转发规则，保留其他配置及启停状态；通知现有运行配置协调机制。
- 通过规则完整元组和配置行创建身份识别本服务的映射，防止删除重建后的同 UUID 网络被误改。

## 运行接口

- 使用所选账号和公网节点的当前在线会话读取实际运行网络。
- 保存前生成仅存在于后端的运行状态证明，数据库事务内再次核对账号和配置权限。
- 不将中心或本地配置改为 Web 配置；候选接口给出不可选原因。
- 运行读取限制为同一会话的两秒请求，读取前后核对会话账号和节点，读取后核对会话仍为当前连接。
- 修正端口映射 IPv6 地址解析，保证运行回读的裸 IPv6 也能参与添加、更新和移除的协调。

## 界面

- 服务表单加入公开开关和配置摘要，独立弹窗编辑公网绑定。
- 使用请求序号隔离切换账号、服务器、设备、弹窗关闭后的迟到响应。
- 保持只读双 IP 展示，新增只读目标地址和传输协议。
- 单次服务保存提交完整意图；可从公开切回未公开后保存撤销。

## 联调与交付

- 主线程手工审阅接口、事务、错误展示、取消和重试语义。
- 本轮不执行测试或构建，整理待测清单并使用中文提交。
- 推送当前功能分支；只读取推送自动触发的既有 amd64 工作流状态。
