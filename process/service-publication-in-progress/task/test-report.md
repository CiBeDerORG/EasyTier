## 2026-10-25 公开服务公网访问入口（本轮）

- 代码范围：`frontend/src/modules/service-utils.ts` 统一计算内网与公网 HTTP/HTTPS 访问地址；服务导航卡片、服务管理、设备服务表格、服务编辑详情与搜索同步接入。
- 地址来源：通过公开记录的当前 `public_ip`、`bind_port` 和 TCP 映射协议生成公网 URL，保留原服务 URL 的 HTTP/HTTPS、路径、查询参数和锚点；不保存第二份冗余地址。
- 防误导处理：没有有效 HTTP/HTTPS 内网地址、未公开、公网 IP 缺失、非 TCP、映射端口非法、非法公网主机名时不生成公网浏览器链接。公开记录撤销或公网 IP 变更后随服务数据刷新。
- 回归用例：新增 `frontend/tests/service-public-links.test.mjs`，覆盖 IPv4、IPv6、协议、公开撤销、非法输入与路径保留。
