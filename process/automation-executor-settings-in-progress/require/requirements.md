# 执行器设置

1. 自动化中心增加管理员「设置」页签，沿用技术控制台卡片、主题及移动端布局。
2. 输入 HTTP/HTTPS 执行器基础地址和 Token。保留/替换凭证显式选择，保存后不回显原值。
3. 数据库存储设置、版本和更新时间；凭证复用现有 AES-GCM 密钥设施。数据库与 `.deploy-agent.key` 一起备份。
4. 保存后即时用于手机连接、投屏、脚本、内部回调、账号撤权和发现端点清理。服务重启保留设置。
5. 单击「检查已保存连接」验证认证及协议身份；读取和普通保存不做连接检测、不定时轮询。结果不能代替手机和视频实机验收。
6. 有活动会话、运行任务、未清理结果或正在派发的请求时拒绝切换；修改地址时先显式释放旧的空闲设备目标。未知清理结果保留原配置。
7. 现有环境变量作为数据库尚无设置时的兼容来源；一个 Web 进程使用一个全局执行器。
