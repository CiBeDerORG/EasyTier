# PLAN-ODS-03 发现快照与同步预览

关联需求：[ODS-R02](../require/require-ods-02-device-discovery-review.md)、[ODS-R08](../require/require-ods-08-results-and-acceptance.md)。实施任务：[ODS-T06 普通发现归一化与预览接口](../task/task-ods-06-discovery-preview-api.md)。

## 小步骤

1. 从已确认网关配置调用一次 `devices.scan`，分别保存本次尝试与来源快照信息；错误携带旧快照时不替换成新的成功结果。
2. 将来源的 `ipv4[]/ipv6[]`、MAC、hostname、来源标签、观察状态和时间规范化为单 IPv4 候选；IPv6 只记录，多 IPv4 不扩展本期模型。
3. 在当前组非网关自身子设备中按 IPv4 初步匹配，补充 MAC/发现名称差异；显示历史复用 IP 和多候选冲突。无 IP 命中时提供同组手选目标入口及服务摘要，排除发起网关。
4. 输出新建、更新、覆盖、跳过的允许条件和阻塞原因，封装快照版本、目标版本及有效期，供 ODS-T07/ODS-T08 提交时重验；预览不写正式资产。

## 依赖与并行边界

ODS-T06 的开发前置固定为 ODS-T03、ODS-T04，无额外联调依赖。基础字段来自 ODS-T02，公共类型与事件来自 ODS-T01，均经前置任务继承。

预览任务唯一拥有归一化、预览存储和预览处理器的新文件；ODS-T07/ODS-T08 拥有正式资产事务，ODS-T09 拥有同步清单组件。T06 在接口冻结后向 T09 提供样例和错误码，T09 可先用契约替身开发，不必等待扫描链路全部可用。共享路由、DTO 导出和页面入口仍由 ODS-T19 接线。

## 输出与完成条件

- 输出可追溯来源的逐行预览、当前组候选目标、差异、动作约束及版本；所有行同时保留历史/部分失败/截断语义。
- 人工显示名称与发现名称分离；缺失来源字段不形成清空动作；组外目标不进入可选项。
- 失败、无快照和空结果均不产生删除指令；同组重复 IP 的行不能全部提交为新建。
- 交接对象为 ODS-T07、ODS-T08、ODS-T09、ODS-T10、ODS-T19；满足 ODS-R02-A01～A07 及 ODS-R08 的阶段错误约定。

后续验证以来源夹具覆盖历史 IP 复用、缺 MAC/名称、跨组同 IP、同组手选目标、预览过期、源状态和空结果。**本轮未执行验证，也未修改 LuCI 源码或部署环境。**
