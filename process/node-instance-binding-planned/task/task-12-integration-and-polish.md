## 联调内容

1. 接通“账号/节点 → 角色 → 持久实例候选 → 规则/地址预览 → 保存 → 列表/目录回显”，两个网关新增入口共用校验与编辑器，普通直属/组内/自身设备各自正确提交。
2. 统一请求和DTO：作用域不能丢失，配置指纹、实例身份、规则标识及幂等重试端到端一致。预览与保存均由后端生成地址；前端不接受伪造地址绕过校验。
3. 接通legacy首次补绑、同实例配置核对、孩子逐条规则/地址修正；网关/直属走binding，旧下挂/自身走address转换继承来源。父网关确认同ID新世代不替代孩子确认，相同rule_key也逐条采纳；网关IP变化触发自身overlay待核对。新直属LAN仅IPv4，旧IPv6仍可维护。读状态不写入，异常仍可管理一般资料、服务与删除。
4. 检查删除生命周期：设备含服务原子删除、网关非空禁删、节点有下属禁删；资产操作不删除或修改EasyTier实例。释放网关绑定后的候选及相关目录刷新正确。
5. 汇总所有新字段和错误文案的中英文key；名称、短ID、网段、状态在筛选/表单/列表表达一致，不暴露网络密钥或不必要内部配置。
6. 收口R01操作可达、R02同名辨识、R03上下文恢复、R04返回位置、R05原/新节点属性长度。视觉处理限定于已有页面的信息结构、窄屏和可访问名称。
7. 旧完整实例配置入口继续可用；不把中央快捷CIDR入口误标为支持箭头映射，不改OIDC/config-server，不增加心跳、轮询、CI工作流或自动网络配置。
