## 工作内容

1. 接入统一新增、编辑、首次补绑和同实例核对入口，按`{resource_kind:'gateway'|'device', record}`区分结果。网关成功刷新目录，并在管理窗口未打开时提供“查看网关”定位结果，不能仅刷新后台目录导致新对象不可见；普通设备沿用按条件清筛选、定位、展开新设备的逻辑。
2. 展示实例/规则或地址来源、绑定状态和可发现的核对动作；保留旧地址快照及设备服务，不将配置失败渲染成空设备或无服务。规则变化后仅提示受影响设备；父网关采纳同ID新世代不把孩子批量标为正常，rule_key相同也逐条address确认来源；自身设备overlay因网关IP变化需单独核对。不在读取时保存资料。
3. 设备计数只统计实体设备记录，网关/节点/服务不加入；服务仍按设备展开，允许多设备同时展开，接口按操作加载。
4. 修复R01常用操作在宽表末尾难发现；结合绑定摘要布局控制表格局部滚动，不新增整页溢出，不大改既有风格。
5. 修复R02筛选及列表同名对象辨识，组显示短ID/实例/网段辅助信息，类型增加短ID；与T09选择器信息一致。
6. 修复R03：确认节点被删/权限撤销时清理失效账号/节点、旧行和操作入口，刷新允许的上下文；临时失败保留旧快照并可重试。切换账号/节点使弹窗、候选、预览和列表请求全部失效，管理员目标账号始终明确。
7. R04返回网络节点列表恢复初始滚动位置，优先在本页相关操作处理；确需路由改动交T12。R05本页节点属性长度按Unicode码点与后端一致，原节点列表属性入口的兼容核对交T12。
