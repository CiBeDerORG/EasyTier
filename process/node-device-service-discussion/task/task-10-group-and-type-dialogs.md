### 业务与工程默认

- 网关组属于选定 owner/node，列出包括空组在内的全部组；不得让设备筛选隐藏空组。名字必填可重复，备注可空，没有组直接挂服务或普通聚合组。
- 一个组至少一条 IPv4/IPv6 标准 CIDR，逐行输入并可增删；主机位不标准给建议值但等待用户改正，重复同组网段拒绝，包含/重叠或不同组相同网段允许。
- 更新网段时预览受影响设备，明确哪些已填 LAN IP 不匹配但允许保存；空 LAN/直属设备豁免。不得静默改 IP/网段、不加二次警告确认，也不标为离线。
- 有设备时组禁止删除；因首阶段不支持移动，提示先删除组内设备，不能提供移组入口。永久删除前说明对象及影响，服务端最终检查并发新增。
- 类型按 owner 账号独立，常用预置为 OpenWrt、手机、电脑、NAS、智能家居、其他；允许新增/改名、使用中禁删，不增加重名禁令。预置由后端每账号初始化一次，前端只读实际类型，不在查询时补回已删预置或生成临时假类型 ID。预置名称被改后显示实际资料，不通过翻译键覆盖用户改名。
- 类型可空；筛选旁“管理类型”打开弹窗；设备表单内不加快捷新增。这些是 P01 明示的工程默认，不能写成 F16–F18 已答决定。

### 实现步骤及组件协议

1. 使用 T08 规定的上下文和记录 ID，组需要 owner/node，类型只依赖 owner；切换上下文销毁旧编辑状态。
2. 管理列表与当前编辑独立，创建/编辑使用弹窗内部明确的编辑区域，避免额外独立菜单；保持名称重复时仍按 ID 操作。
3. 逐行 CIDR 输入显示格式错误和标准值建议；通过 T08 调用 T05 的 `POST /assets/validation/gateway-subnets`（`/api/v1` 下），按 T01 传 owner、node、可选原组 ID 和待保存网段，读取字段错误/警告/受影响设备。失焦或明确预览操作触发一次，晚到响应必须对应当前输入；预览不保存，最终提交仍校验。不引入旧 IPv4 parser 副本、私有 IPv6 算法或周期预览。
4. 按共享幂等协议保存创建；成功发出 `changed`，让 Page 按当前上下文重读组/类型选项以及受影响列表。失败仍保留打开的输入，取消直接丢弃。
5. 类型改名保留稳定 ID，引用中删除冲突清楚提示；后台已删除/权限失效时不继续操作旧记录。
6. 输出全部翻译 key、非阻断警告文案和主页面入口所需参数，由 T14 统一合并语言/菜单资源。
