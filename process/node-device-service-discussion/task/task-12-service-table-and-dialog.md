### 实现步骤

1. 面板在设备展开时读取服务，展开设备各自维护加载、空态、错误与手动重试。CRUD 完成或用户刷新时更新，不对未展开设备预取、不定时拉取。
2. 展示服务名称、协议、单端口、可选访问链接和图标，提供新增/编辑/删除。服务只挂设备，不允许选其他设备或直接挂网关组，不新增服务数量指标。
3. 弹窗填写名称（必填）、TCP/UDP/两者（至少一种）、一个端口、选填备注/访问链接/内置图标；端口合法范围按 T01，双协议作为一个服务原子提交。
4. 同设备同协议和端口冲突就近提示。TCP 53 与 UDP 53 可分别存在，TCP+UDP 53 与任一单协议 53 冲突；不把服务同名当冲突，也不探测真实监听端口。
5. 访问链接可空；有值仅接受完整 HTTP/HTTPS 网页地址，可含路径，显式按钮/链接新标签页打开，使用安全的新窗口隔离。不得从设备 IP/端口自动补值，不支持 SSH/RDP 或自定义客户端唤起。
6. 内置图标用固定 ID 映射已有素材，未选时默认；不把任意 class/HTML/URL 当图标，不增加图片外链、上传、抓取或图片存储。具体小型图标清单由工程确定，保持 API 值可识别。
7. 单条服务永久删除前说明对象；所属设备已被删除时结束该对象操作，不让更新恢复记录。设备级联由 T06，面板对父设备消失作局部清理。
8. 新增同次重试复用 T08 操作身份；编辑采用最后保存语义，仍展示权限/字段/唯一性失败。主动关闭直接丢弃未保存输入，不做确认或持久化；打开窗口失败保留输入。
9. 输出表格 slot 使用说明、默认图标及可选 ID 清单、翻译 key 清单给 T14；基本窄屏、主题、键盘和错误文字在独占组件内完成。

### 验收条件（未执行）

- 两台设备同时展开，各自加载与重试，不相互收起或清空；收起/切换账号节点后的晚到响应不能写入新对象。
- TCP/UDP/双协议冲突按设备范围执行，失败不保存一半；单端口不能伪装为端口范围或多端口。
- 无链接可正常保存；网页链接新标签页且不承诺可达；非 HTTP/HTTPS 不作为可点击入口。
- 仅内置图标，未选默认，没有图片请求/上传入口、公开开关、目标 IP 选择或状态轮询。
- 取消不提醒，打开时失败保留输入，同次重试不重复创建；删除/父设备消失不复活资料。
