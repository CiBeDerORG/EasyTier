交付下挂设备表格和居中编辑弹窗，服务展示通过 slot 接入，不混用现有注册节点。来源：原始设备列表/下级服务需求，Q02–Q06、Q09–Q16、Q20/Q21、Q31–Q35、Q44–Q47；F04–F06、F09–F15。

`DeviceList.vue` 已有 DataTable、`expandedRows` 和分页，但行是注册节点且展开 `DeviceDetails`；`confirmDeleteDevice` 调 `delete_machine` 并可能拉黑。新资产必须独立组件和 API，不能复制旧删除行为。`DeviceAttributesDialog.vue` 的居中弹窗、独立输入和失败显示可作参考，原地点/型号编辑继续保留。

### 文件所有权与输入输出

- 独占新 `easytier-web/frontend/src/components/node-assets/AssetDeviceTable.vue`、`AssetDeviceDialog.vue`。
- 表格接收 T08 契约中的设备行、加载/错误、总数/页码、展开 ID；发出翻页、展开/收起、编辑、删除、添加服务事件。
- `services` 具名 slot 提供稳定设备记录，由 Page/T14 注入 T12 面板；本任务不 import 或编辑尚未完成的服务组件，不改 Page/API/路由/YAML。
- 弹窗接收完整 owner/node、可选原记录、组/类型选项和 ApiClient。创建/编辑成功回传结果；Page 决定重读、清空筛选和定位，本任务不暗改父页面条件。

### 实现内容

1. 展示名称、型号、设备类型、所属组或直属、组网 IP、内网 IP、必要备注/自身标记及操作；名称重复仍通过 ID 区分。不新增设备在线状态或启停功能。
2. 支持多行同时展开，失败与空服务态交 T12 局部处理；展开不触发全表服务预加载。总数只统计命中的设备记录，包含自身设备，不加组/节点/服务计数指标。
3. 名称必填；型号、备注、类型可空。组网 IP 必填且一条，内网 IP 可空且最多一条，纯 IPv4/IPv6，不混 URL/域名/端口/CIDR。
4. 新增默认直属当前节点，即使当前筛选某组也不自动选组；保存前可选同节点一个组。编辑的 owner/node/group 只读或不发送，不能提供移动入口。
5. 组内可手动标记“网关自身设备”，每组最多一条；直属设备无此标记。前端显示已知冲突但以后端结果为准，不自动创建或关联注册节点。
6. 通过 T08 调用 T06 的 `POST /assets/validation/device-address`（`/api/v1` 下），按 T01 传 owner/node、可选组/原设备 ID、组网 IP 和内网 IP。失焦或明确操作触发一次，匹配当前输入才展示响应；纯预览不保存且最终提交仍校验。LAN 不匹配组网段时编辑提示但可保存，保存后列表 LAN 旁继续显示可理解提醒；无 LAN/直属免匹配。非空 LAN 在整个节点禁重，组网 IP 可重复；不混淆警告与保存失败，不复制旧 CIDR 算法或新增定时预览。
7. 删除前说明设备及全部服务将永久删除，确认后按服务端提交时数据级联，包括确认弹窗后新建的服务；不要让弹窗旧计数成为版本锁或要求再次确认。仅删除新资产，不调用机器删除或拉黑。
8. 取消/关闭直接丢弃；仍打开时失败保留输入。通过 T08 幂等协议重试创建，编辑最后成功保存生效；保存后的显示动作回交 Page 按 F12/F14 执行。
9. 使用局部样式完成表格窄屏可操作、按钮文字/焦点/错误反馈，不修改全局主题；输出中英 key 清单交 T14。
