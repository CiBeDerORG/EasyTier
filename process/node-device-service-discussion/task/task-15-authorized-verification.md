## 必要场景矩阵

|编号|场景|应观察的结果|
|---|---|---|
|V01|两个普通账号、一个管理员；伪造 owner、组/设备 ID|普通账号隔离；管理员真实授权且先账号后节点；目标归属不变|
|V02|节点含空组/设备，发删除，同时尝试新增子项|删除在停止网络/配置清空/拉黑前拒绝；无孤立记录|
|V03|非空组删除、在用类型删除；已有服务设备删除与新增服务并发|前两项拒绝；设备事务删除执行时全部服务，后续服务新增不产生孤立记录|
|V04|IPv4/IPv6 同值不同文本、空 LAN、同节点跨组 LAN、重复 overlay|规范化唯一正确；空 LAN 多条可存；overlay 可重复；不合并记录|
|V05|带主机位 CIDR、重复 CIDR、包含/重叠、LAN 不匹配|标准值仅提示需手改；同组重复拒绝，重叠允许；不匹配 warning 可保存且列表保留|
|V06|一组两个自身设备；直属设备标自身；PUT 改归属|组内最多一条、直属不能冒用组自身；归属变更拒绝|
|V07|TCP 53、UDP 53、双协议 53 并发/冲突修改|单协议可各自存在；双协议冲突原子失败，不留一半占用|
|V08|响应丢失后同 request ID 重试、后端重启后重试、同 ID 改内容、删后重放|不重复创建；不同内容冲突；已删不复活；仍做权限检查|
|V09|两个页面后保存覆盖；更新已删除记录|允许最后成功保存覆盖合法字段；不能更新复活、不免除唯一性|
|V10|零实例/离线节点进入、查询按钮、多个展开、局部加载失败|可管理资料；筛选草稿不偷生效；服务按需；错误不显示成空列表/0|
|V11|新增默认直属、隐藏于筛选的新设备、取消和失败、返回旧列表|隐藏时清组/类型/关键词并定位展开；匹配时不乱清；主动取消弃输入；失败保留；返回初始状态|
|V12|HTTP/S 选填链接、恶意/其他协议、内置图标、长文本|无链接可存；非法协议拒绝；安全新标签；无外链图片/上传|
|V13|旧实例设置、节点属性、OIDC/config-server、external webhook|原操作/认证保留；新资产功能在 external webhook 不开放|
|V14|抓取新增资产/计数请求，静置页面后观察|无新增周期拉取；已有旧节点轮询不误判成新资产轮询|
|V15|中英文、明暗、小屏、键盘；新页与旧节点入口截图|关键信息/操作可读可用，旧布局保持；截图对应本次制品版本|
|V16|旧库备份副本升级、重复启动、备份恢复|原记录不丢、迁移一次、类型预置不复活、恢复步骤可执行|

以上是设计阶段的验收矩阵，不代表每个分支均已执行；实际执行范围及未执行项以最终报告为准。不为简单文案或样式逐条补镜像测试；把自动化投入权限、唯一性、幂等、删除竞态及真实关键流程，视觉细节可记录人工/浏览器观察。

## 报告与完成定义

记录代码/制品版本、环境、数据准备、获准范围、实际命令和退出结果、每个场景结果/未执行原因。模拟 API 页面检查与真实 DB/会话 E2E 分开记录；旧测试通过不能代表新功能通过。发现问题回到唯一 owner 修复，只有变化影响范围需重测，不无故反复全量 CI。
