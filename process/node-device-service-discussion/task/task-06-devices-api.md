### 具体步骤

1. 提供单节点上下文下的设备列表、详情、创建、编辑、删除。设备 ID 独立 UUID，owner/node 固定，group 可空；创建时可选择同节点组，之后禁止进组、换组、退组和跨节点移动。
2. 字段包括必填名称和单一组网 IP、选填型号/单一 LAN IP/备注/type_id、可选网关组、网关自身标识及创建更新时间。类型可空为 P01 工程默认，不伪装为 F18 答复。
3. 父节点/组/类型必须在正确 owner 范围，组还须属于同节点。直属设备不得标网关自身；组内至多一个自身设备，手工创建、不强制存在，不与注册节点自动同步。
4. 用 T03 规范化 IPv4/IPv6：组网 IP 必填可重复，LAN 可空但同节点所有设备统一非空唯一，更新排除自身。内网不在组任一同族 CIDR 中返回提醒而不阻止保存；直属/空 LAN 免检查。
5. 新增设备使用 T04/T13 的节点生命周期写入协调及 T03 幂等，在同一事务检查父对象和写入。创建返回稳定 ID 及定位资料，供前端保存后展开；不能按同名、同型号或同 IP 自动合并。
6. 列表必须包含全部直属与组内设备；可选具体 group/type 和关键词取交集。关键词只搜名称、型号、组网 IP、LAN IP；不增加直属筛选、服务名搜索、按物理设备去重或状态过滤。
7. 按创建时间倒序加稳定 ID 次序分页，每次查询最新资料。返回列表匹配总数及 LAN 警告信息，不初次附带全体服务。提供按节点批量 count 的数据查询供 T04，计入自身设备而不计组/服务。
8. 编辑仅更新普通资料，最后成功保存生效，不允许借旧表单改变归属或复活已删记录；类型更换不改拓扑。删除经前端确认后事务删除设备及执行时全部服务/绑定，确认期间新增但先提交的服务也包含在内。

补充只读预览：提供 `POST /api/v1/assets/validation/device-address`，输入 owner/节点上下文、可空 group/device ID、`overlay_ip` 和 `lan_ip`。在受权范围内读取必要的组网段，返回 `field_errors`、`warnings` 和规范值建议；编辑场景按 device ID 排除自身唯一冲突。预览不保存、不探测网络，由表单失焦或明确操作触发，不能定时查询；正式提交重新校验并依靠事务/唯一约束处理预览后发生的变化。
