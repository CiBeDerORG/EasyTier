### 共同规则

1. 设备和服务均为居中弹窗。主动取消、关闭或离开直接丢弃未保存输入，不确认、不持久化草稿；请求失败且仍打开时保留输入。关闭不代表取消服务端已收到的提交。
2. 同一次新增的重试复用同一个操作身份和提交内容；主动再次新增才是新操作。普通编辑最后保存生效，但无权限、固定归属修改、字段非法和唯一性冲突仍拒绝。
3. 名称必填且可重名；以稳定 ID 操作。同名选项用补充信息区分，不根据名称自动合并。
4. 网关组至少一个标准 IPv4/IPv6 CIDR，逐行增删；设备组网 IP 必填、内网 IP 选填，均最多一条。非空内网 IP 在整个节点禁重；网段不匹配只警告，编辑和列表均可理解地展示。
5. 设备默认直属节点，创建时可选同节点组；保存后归属不可改。自身设备标记仅在组内有效，每组最多一个，由后端最终保证。
6. 设备删除需确认并删除提交时全部服务；组有设备禁删。前端显示删除影响，不能把客户端数目作为阻止新增服务后的级联删除条件，也不能复用旧删除注册机器/拉黑接口。
7. 服务单端口、TCP/UDP/两者；同设备同协议端口唯一。链接选填，仅 HTTP/HTTPS 新标签页；只选内置图标、未选默认，无首阶段公开开关。
8. 基本手机适配、现有主题/语言、键盘和错误文字属于工程质量；本轮不新增一套独立手机版产品，不新增长连接或定时读取。

### 工程默认与验收

类型按所属账号独立预置 OpenWrt、手机、电脑、NAS、智能家居、其他；类型可空，不增加必填约束；筛选旁通过管理弹窗维护，表单内不做快捷新增，不新增类型重名禁令。这些是 P01 的本轮工程默认，F16–F18 未答撤回，不记为用户批准。

组编辑中的受影响设备提示与设备表单的网段匹配使用 T01/T08 的服务端纯校验预览契约：T05 提供 `POST /assets/validation/gateway-subnets`，T06 提供 `POST /assets/validation/device-address`，均置于 `/api/v1` 下。返回字段错误、非阻断警告、受影响设备及标准 CIDR 建议，不保存、不自动修改。用户失焦或明确操作触发一次，请求结果与当时输入/上下文匹配；不能由 T10、T11 复制旧 IPv4 parser，也不新增定时预览，最终保存仍重新校验。具体字段在 T01 冻结。

验收覆盖各任务明细中的正常、空态、错误、删除影响、同次重试、数据隔离及基本响应式。T14 先完成实际组装与接口联调，T15 再在测试授权后执行验收；本轮仅文档，未执行任何检查。
