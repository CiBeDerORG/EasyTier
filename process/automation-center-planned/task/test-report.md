# 实施阶段与验证记录

## 阶段拆分

| 阶段 | 交付 | 验收重点 |
| --- | --- | --- |
| 本次 | 菜单、准备入口、统一主题、方案 | 入口真实、无伪功能、无后台请求、中英文/窄屏 |
| P0 | 2 台 Android 的接入与协议验证 | ADB 授权、H.264 浏览器解码、旋转、单机输入、断连清理 |
| P1 | 画面墙与单机控制 | 10–20 台实际容量、资源预算、权限与控制占用 |
| P2 | 批量动作与逐台结果 | 固定目标、去重、部分失败、取消和未知结果处理 |
| P3 | 录制、编辑、版本化脚本与执行 | 参数保密、预检、人工继续、失败恢复；语义定位另行验证 |

首期平台、手机数量、USB/无线/跨地域方式及活动任务内部等待策略尚待确认。实现手机控制之前先完成 P0，不对尚未验证的机型和规模给出工期或兼容性保证。
