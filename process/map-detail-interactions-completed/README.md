# 地球细节与站点网关展示

当前分支：`feat/map-detail-interactions`，基于已发布源码及记录 `509a787f`。本轮修正地球继续缩放、真实行政区域、近距离连线重叠、节点标记过大，以及网关和自身设备重复显示的问题。

状态：实现与本轮验证完成。前端生产构建、34 项单元测试和补丁检查通过；浏览器首轮其余 14 项通过，修正后的 5 项针对性复测全部通过，覆盖 19 个唯一场景。已查看行政区域、手机近景、邻近线路和网关合并截图。未提交、推送或更新镜像。入口：[需求](require/README.md)、[计划](plan/README.md)、[执行记录](task/test-report.md)。

地球按距地高度连续缩放，最低约 5.1 km，选中节点保留当前高度；国家/省级真实行政数据随视角显示；节点改为 5/7 px 圆点与 24 px 点击区域；相邻线路分道、同址关系保留、多条命中提供选择；单网关有自身设备时合为一个可选中心设备，多网关保持独立。

行政数据为固定版本 Natural Earth，包含 242 个国家/地区、4,596 个一级行政区，不含市县街道或实时版图更新。离线数据体积约 7.30 MB（gzip 约 3.01 MB），随地球组件按需加载。
