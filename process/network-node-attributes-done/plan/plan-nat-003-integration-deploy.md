# IP 接入、联调部署与截图

[计划汇总](README.md) · [任务 NAT-003](../task/task-nat-003-integration-deploy.md)

## 现状与目标

前轮 IP 工作树基于用户管理分支；main 的生产连接管理实现可接入这些 IP 改动，但用户管理特有测试身份结构和迁移不能直接带入。main 已支持 `easytier-web --features embed` 构建 Web/API/config-server，本次沿用现有启动能力部署。

## 分阶段执行

1. **可并行准备**：root 仅移植 `client_manager` 中来源 IP、Session、Storage 和本地定位相关逻辑及适用于 main 的测试；不写后端 agent 管理的 DB/REST 文件。使用有效连接观察 IP，不新增协议字段或定时任务。维护单节点写入顺序，避免旧连接快照覆盖新连接；失败不影响正常认证和配置。
2. **联调门禁**：NAT-001、NAT-002 交付后，统一检查接口、类型、迁移、编译和针对性测试。发现跨模块问题，交回对应文件负责人修改，再按失败范围复验；不以静态实现替代验证结果。
3. **真实部署**：构建当前分支前端和 embed 后端，使用独立数据库、端口及明确的演示节点运行；完成登录、打开原设备列表、保存属性、页面重载及清空复查。
4. **截图与记录**：截取原列表中的属性展示、编辑弹窗和窄屏交互；记录部署地址、源码基线/分支、运行方式、验证结果和剩余限制。共享截图中不展示登录口令、令牌或敏感配置。

## 验收与限制

本计划完成 NAA-04 的实际链路、NAA-05 和 NAA-06。IP 定位只保证所配置本地库提供的信息；内置 Country 库无区域/城市时保持为空。无公网直连证据时不能宣称已验证特定 OpenWrt 的真实公网地址，应说明实际测试连接类型及数据来源。

实现、联调、部署和截图已完成；结果见[验收记录](../verification.md)。仅云环境演示实例已部署，未连接用户实际 OpenWrt。
