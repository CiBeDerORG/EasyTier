# 设备列表属性编辑

[计划汇总](README.md) · [任务 NAT-002](../task/task-nat-002-card-editor.md)

## 现状与目标

main 的 `DeviceList.vue` 已有卡片、表格、手机列表、别名编辑、删除、管理、搜索及刷新。保留现有布局和事件，在设备单项增加独立“编辑属性”入口；地点和设备型号作为单卡的简短属性展示，不改成拓扑页面。

## 实施内容

1. 扩展前端设备类型及 API 方法，保留列表新返回的八个字段；只允许提交两个手填字符串。
2. 新增 `DeviceAttributesDialog.vue`，编辑地点和设备型号，展示只读来源 IP、IP 所在地、状态和观察时间；未提供值或无法定位时给出明确占位。
3. 打开弹窗时复制当前值为本地草稿，既有列表刷新不得覆盖输入。取消不请求保存；提交期间防重复；失败保留草稿并显示错误；关闭或切换设备后忽略过期响应。
4. 前后端使用一致的控制字符、Unicode 字符数和长度规则；支持空字符串清空。保存后以服务端标准化结果更新对应设备。
5. 增加中英文文案和键盘可操作的表单标签、错误提示；验证手机窄屏。必要的类型一致性修复限制在本任务前端文件范围。

## 交付与验证

交付列表入口、弹窗、类型、API、语言包及针对性前端测试。覆盖取消/保存/清空、校验、请求失败、重复提交、刷新保留草稿及旧操作回归，对应 NAA-03。使用固定响应的浏览器测试只能证明交互；实际持久化和最终截图由 NAT-003 对真实后端验证，当前不能以测试夹具截图作为交付证据。

本任务可按固定 API 契约与 NAT-001 并行。内部可将独立测试文件交给其他 agent，但 `DeviceList.vue`、共享类型和语言包仍各只有一个写入负责人。
