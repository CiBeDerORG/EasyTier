# 产品验收基线：用户确认的12项

任何改动须在对应 AC 用例证据齐全后才可将该项标记为完成；不能用「代码已提交」替代「真机验收」。

| 编号 | 场景 | 验收要点 | 计划 |
|---|---|---|---|
| AC-01 | 卡片拾取模式 | 打开实时画面后，点击拾取图标进入/退出；展示关闭、初始化、开启、异常四态；退出恢复手控，不关闭画面 | M1 |
| AC-02 | 右键菜单 | 拾取模式下鼠标右键在真实视频像素区域打开快捷菜单，坐标正确；非拾取状态保持浏览器/手机原既有行为；触屏提供长按替代 | M1 |
| AC-03 | 控件树属性配置 | 右键位置定位当前控件；可查看树、属性、唯一候选，配置动作/参数；旧树和不唯一候选不可无提示落库 | M1 |
| AC-04 | 首步录入自动收窗 | 确认配置生成脚本第1步并关闭属性窗；拾取模式和实时画面不退出；重复确认幂等 | M1 |
| AC-05 | 连续多步 | 重复右键可形成第2/3/4步；次序、步骤ID和当前草稿正确；不反复打开脚本库 | M1 |
| AC-06 | 卡片脚本进度 | 卡片可见当前脚本、步骤序号/类型、草稿未保存/同步中/已保存状态；支持折叠且不遮挡主画面 | M2 |
| AC-07 | 旧步骤编辑与重拾 | 点击步骤编辑/替换定位，保存后ID不变、仅更新目标字段、不新增步骤；可取消不改原步 | M2 |
| AC-08 | 定位演示 | 只读定位刷新树并高亮匹配目标；无任何 Android 动作；明确区分于有副作用的真实试跑 | M2 |
| AC-09 | 单步自动准备 | 选择单步骤试跑设备自动检查ADB、必要时连接并准备UiAutomator2、展示阶段/超时/失败；不自动无线配对 | M4 |
| AC-10 | 试跑结果回步修复 | 结果关联原 step_id 和 run_id，回到同一草稿步骤；失败可修改、重新验证，历史执行记录不可变 | M4 |
| AC-11 | 保存恢复跨设备 | 草稿可保存并重新打开；可在其他授权手机使用；设备变更时明确检查定位目标，绝不静默沿用不匹配坐标 | M3 |
| AC-12 | 连接与编辑恢复 | ADB/投屏断开、切换页面、取消本次编辑，已经确认并持久化的步骤不消失；网络保存未确认须显式提示 | M3 |

## 额外不可破坏行为
- 右键只拾取，不发送手机点击；普通左键继续控制手机。
- 属性窗确认仅追加一条步骤；有重复响应/重入时不重复追加。
- 编辑旧步骤必须保留旧 `step.id`，参数及条件分支不可被替换目标意外清除。
- 完整脚本/历史执行结果不可因试跑而静默改写。
- UI 树快照有时间差，坐标位置、分辨率、方向、目标指纹变化必须重验。
- 拾取成功 ≠ 定位演示成功 ≠ 真机执行成功，状态文案明确区分。
- 用户已确认并被服务端持久化的步骤，不受 ADB 断开或网页切换影响。保存失败不谎报「已保存」。
