# 产品交互路径与异常闭环

## 流程 A：首个及连续步骤
1. 打开一台手机实时画面，点击卡片拾取开关。只允许在该卡片上的按钮进入模式，状态有关闭/准备中/拾取中/错误。
2. 正常左键导航；在视频有效画面右键（触屏长按）打开菜单，不发送触控到手机；超出画面黑边不可拾取。
3. 菜单：`查看并拾取控件`（默认）、`快速添加点击`、`快速添加长按`、`等待出现/消失`、`属性检查`、`刷新控件树`、`退出拾取`。仅展示当前能力支持的动作；其余复杂操作进入完整属性配置。
4. 根据右键位置读取或刷新UiAutomator2树，找到候选控件，展示属性与定位候选。点击/长按/输入/等待/断言等必填属性必须完善才能「确认录入」。
5. 第一次确认追加第1步、收起属性窗、返回**原卡片原画面**、保持拾取开关打开；再次右键追加第2/3/4步；每步唯一ID，不能重复。
6. 草稿在同一账号工作区内是**一份活跃脚本**，手机是拾取/验证目标；跨设备切换时仍要显示脚本身份及机型匹配风险。
7. 卡片下方折叠步骤条显示最新步骤，录入结果以「已加入草稿/保存中/已保存/未同步」清楚反馈。

## 流程 B：编辑与定位演示
1. 点击步骤条某步打开简洁编辑面板，复杂流程跳转脚本库时保留当前选择。
2. 点击「重新拾取」使**下一次右键**进入替换模式；确认后只改原步骤目标及必要字段，保留ID、其余参数和条件块。
3. 「定位演示」只读取最新层级，命中0个显示缺失、1个高亮、多个显示歧义；绝不执行 tap/input。
4. 用户明确点击「单步试跑」才真正向设备发送动作，有副作用操作需明确同意。

## 流程 C：保存、恢复、跨设备复用
1. 打开、切换和关闭画面都不删除已确认步骤；完成录入的步骤写入**独立服务端草稿**，拥有草稿ID和 revision。
2. 保存中断时展示「未同步」，不得冒充确认持久化；可继续编辑，但离开时提示未落地修改，网络恢复后同一修订安全重试。
3. 草稿可人工命名/保存为脚本；脚本库与卡片使用同一源；重新打开保留步骤顺序与定位条件。
4. 同一脚本在其他授权手机复用时先检查目标绑定，禁止无提示复制依赖原屏幕尺寸的绝对坐标；建议重新定位或按相对坐标经人确认。

## 流程 D：试跑、回步、修复
1. 选中目标手机后自动检测ADB/必要时连接/控件组件就绪；显示每阶段与超时；**不自动无线配对**。
2. 试跑有副作用时需确认；执行前关闭本页拥有的视频控制会话、确认执行器资源清理，再独占执行；不能偷用其他人的会话。
3. 运行结果按`run_id`+`device_id`+`step_id`回写步骤状态。用户回卡片可见失败步骤与原因。
4. 失败后点「修复」定位到原步骤，改参数或重新拾取，再重新验证；旧运行记录不可变；结果未知不得自动重放。

## 必验异常分支
- ADB断线/手机息屏；UiAutomator2卡死/准备超时；视频迟到；旋转/分辨率不匹配；树为空/截断；控件遮挡、重复候选；触屏长按与真实长按操作冲突；全屏弹层被浏览器顶层遮住。
- 另一个浏览器抢占同设备；手动控制或录制/群控同时发生；从一个脚本切换另一个；两浏览器编辑同一草稿产生 revision 冲突；服务器保存失败；离开页面时尚有未同步步骤。
- 有副作用单步执行失败、运行状态未知、执行器掉线、步骤返回后设备页面已变化。
