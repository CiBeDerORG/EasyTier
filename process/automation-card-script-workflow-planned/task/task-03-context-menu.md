## 本轮交付（2026-10-27）
- 新建 `CardContextMenu.vue`，菜单覆盖于**原手机画面内部**，支持鼠标右键、键盘菜单键及 Shift+F10，适配全屏；Esc关闭当前菜单，继续拾取。
- 菜单分组：查看控件树及属性、刷新控件树、配置点击/长按/输入文字/等待出现/等待消失/检查控件/属性断言、退出拾取模式。采用菜单 `role="menu"` 与键盘方向键/Home/End 焦点导航，菜单靠边收敛并可滚动。
- `PhoneCard.vue` 触屏长按约550ms唤出菜单；正常短按/滑动仍可发送至 Android；长按拾取不会同时发送 Android 按下或长按。普通右键不向 scrcpy 发触摸。
- `AutomationCenter.vue` 接入菜单动作：刷新控件树通过现有授权 UiAutomator2 只读 API；其余动作打开既有控件检查与配置窗口，记录原右键位置及拾取会话版本，提示用户**仍需手动选中并确认定位、动作**。刷新旧弹窗用版本键防止沿用上次选中元素。
- 为避免浏览器全屏 top-layer 隐藏现有属性窗口，只有选择“查看/配置”后才退出全屏；**菜单本身不退出全屏**。
- **仍待 T04/T05/T06**：右键位置自动命中目标、默认定位条件与动作预选、直接快捷录入与自动收窗；本轮不谎称菜单已能一键生成步骤。
