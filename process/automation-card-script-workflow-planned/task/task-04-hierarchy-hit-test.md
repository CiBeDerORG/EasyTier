## 本轮交付（2026-10-27）
- 新增纯函数引擎 `automation-pick-engine.ts`，接收设备指纹、当前视频物理像素右键坐标及只读 UiAutomator2 快照，生成候选命中结果、最靠内层控件 ID、最近可点击父节点和可选的唯一定位候选。
- 严格验证目标指纹、快照采集时间（默认20秒上限）、视频与快照的屏幕比例/方向、点位边界、节点 ID 唯一性、控件矩形与截断状态；从编码视频到设备快照按归一化比例映射，拒绝不可信的画面。
- 命中优先最小面积控件，其次启用可点状态、层级深度；不使用 instance 或未确认的 XPath/坐标兜底。调用现有 `rankLocatorCandidates` 验证候选唯一性，不保存选择。密码控件只返回脱敏提示、不使用文字/描述作为候选。
- `UiInspectorDialog.vue` 将原本内联的点击命中替换成统一引擎；若来自卡片右键，则**新读取**控件树后一次性预选命中节点、展开祖先，展示定位候选，仍要求用户手工确认后才可生成步骤。
- `AutomationCenter.vue` 为 Inspector 传递受会话世代/账号/脚本绑定保护的首个右键点位；脚本库旧步骤重拾与旧式不带点位的入口保持独立。
- **不属于 T04**：自动勾选匹配候选、默认菜单动作选择、确认后关窗、连续追加去重（T05/T06）；快照时间过期后自动重试也不在本轮强行执行。

## 交付范围
抽离元素按bounds定位、最小元素/可点父节点候选、坐标与fingerprint/尺寸版本；失效需重新读树；保持唯一性规则。
