## 实际交付（2026-10-27）
- `AutomationCenter.vue` 在单次右键打开 Inspector 时，保存不可从当前状态临时重建的录入令牌：弹窗 generation、设备 ID、账号/设备指纹/投屏会话/草稿 ID 与修订、拾取 generation 与 snapshotGeneration。
- `UiInspectorDialog.vue` 提交步骤时携带该令牌及同步确认回调，`committing` 锁避免双击；控制器还在写入前校验该令牌及右键点位上下文、当次草稿归属与会话状态。令牌仅允许成功一次，迟到事件或另一弹窗的事件均不追加。
- `automation-draft.ts` 新增 `appendPickedAutomationStep`：明确要求拾取产生的步骤 ID 非空且在草稿中尚未存在；该路径不会像录制批量导入那样自动更换重复 ID。
- 录入成功后**仅调用 `closeInspector()` 关闭属性窗口**，并提示「第 N 步已录入，可继续右键」；不关闭 PhoneCard 的视频，也不改变 `pickerContexts[id].phase`。再次右键可生成第2/3/4步。
- 取消仅关闭窗口；校验或草稿长度不符时不写入，显示错误，并按失败性质允许重新确认或要求重新拾取。
- **一并修复 T05 编译阻断**：历史自动构建 `40458079627` 报 `UiInspectorDialog.vue:476 TS1003`，原因为抽取属性面板时遗留不完整的 `<small v-if=...>` 标签，已恢复视频方向提示和正确的 `</section>` 闭合。
