## 3. 高风险演练顺序与中止规则

1. **只读阶段**：先采集镜像 digest，确认 2 台已授权测试手机和原视频 ID；打开关闭浮窗、拖动、全屏、拾取/定位只读、高亮与条件编辑；不得为看画面直接执行手机动作。
2. **正式脚本与数据阶段**：草稿 CAS、保存/删除修订保护、克隆新 ID、恢复/重拾、空脚本不可试跑。核对账号、设备 ID、指纹和草稿 revision。
3. **授权下的真实动作**：先单台低风险步骤，再 2 台授权设备批量。预先确认执行范围；记录请求 UUID/运行与步骤 ID，超时/失败只能查历史而不是重新按 ▶。
4. **竞争与故障阶段**：双浏览器观看和写锁竞争、切页、断网、手机断开、全屏切换、Executor 重启/清理未知；对不可恢复的动作/连接状态立即停止新动作并取证，不自动重试。
5. **验收结束**：汇总 FF/AC 逐条结果，明确 PASS/FAIL/BLOCKED/NOT RUN、复现路径和脱敏证据，只有所有强制行为经实际验证才允许 T51 判为完成。
