## 多 Agent 并行策略与唯一写入文件
- **集成负责人**（T01/T06/T11/T16）：唯一修改 `AutomationCenter.vue`、`ScriptLibrary.vue`、`automation-draft.ts`、`automation-api.ts`，负责合并/接线；不要同时开两个集成任务。
- **卡片 Agent**（T02/T03）：独占 `PhoneCard.vue` 和新增卡片拾取/菜单组件。T03 依赖 T02 时串行；其他 Agent 不直接编辑 PhoneCard。
- **Inspector Agent**（T04/T05/T09）：独占 `UiInspectorDialog.vue`、Locator/Inspector实现，T04→T05，T09在M2接入时独立组件；其他 Agent 不复制控件候选算法。
- **步骤 Agent**（T07/T08）：独占新建 `CardStepTimeline.vue`、`CardStepEditor.vue`；`ScriptStepEditor.vue` 保留兼容并配合集成负责人合并。
- **后端数据 Agent**（T10）：独占草稿数据迁移/API（与执行器运行模块分开）。
- **运行 Agent**（T12/T14）：独占新增准备/运行状态组件与 composables；不改中心控制文件。
- **执行器/服务端 Agent**（T13）：独占 `runs.rs` 和 executor 运行排他相关文件，不能覆盖 T10 草稿 API。
- **修复 Agent**（T15）：独占 `RunHistory.vue` 与失败修复模块；接口交付集成负责人。
- **测试 Agent**（T17）：独占新增测试文件；QA（T18）维护`test-report.md`和验收记录。
- 同一文件出现共享需求时先提交接口契约，再由唯一写入人接线。各模块使用 props/events/纯函数协作。
