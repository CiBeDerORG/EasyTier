# 用户管理：需求与进度汇总

用户本轮要求新增“用户管理”菜单，展示全部用户并支持删除；删除时禁用该用户全部网络，网络节点、设备和服务资料暂不处理。基于现有`feat/node-attributes-main`继续实现，不切回其他历史分支。

|项目|进度|问题与处理|
|---|---|---|
|代码核对|已完成|users外键会级联删除节点/网络，不能硬删；中央发布器与旧心跳可能重新启用网络|
|实现方案|已确定|逻辑删除保留ID及用户名占位；管理员操作；持久禁用、发布/写入屏障、在线停止及真实结果反馈|
|后端认证|已实现，未验证|新增000014迁移；登录、旧会话、OIDC与config-server本地认证拒绝已删除账号；保留原协议|
|网络闭环|已实现，未验证|持久禁用、中央发布和写入屏障、在线停止；原Web及internal写接口共用业务锁，未增加轮询/任务|
|前端与接口|已实现，未验证|管理员菜单、全部用户状态与删除确认；禁止自删，保留资料说明；重复删除可重试|
