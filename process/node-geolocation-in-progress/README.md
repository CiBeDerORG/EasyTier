# 网络节点地理定位

## 当前进度

- 状态：实现与手工源码审阅已完成；运行验证待授权。
- 目标：在普通网络节点和节点资产的基本属性中设置国家、省州/地区、城市、区县及经纬度，为后续地图拓扑提供结构化数据。
- 当前模式：调试模式；本轮只做实现、源码审阅、提交和推送，不主动运行测试、构建、类型检查、lint 或其他验证命令，也不手动触发 CI。

## 已确定的实现边界

- 新增独立的 `geo_location`，与自动观察的 IP 归属地和原有安装位置说明分开保存，心跳和重连不覆盖手工位置。
- 坐标统一为 WGS84；经纬度须同时填写或同时为空，允许先只填写行政区信息，不使用 `(0, 0)` 表示未设置。
- 选择地图点后自动解析国家、省州/地区、城市、区县，允许手工修正；解析失败不丢失坐标，不阻止合法的手工保存。
- 两个属性编辑入口复用同一编辑组件，选择结果仅修改草稿，随原属性表单保存；取消不写入节点。
- 地图使用 Leaflet 和 OpenStreetMap 标准底图，逆地理解析默认使用 Photon；服务端提供可配置上游、缓存、限速和超时，客户端按用户操作请求。
- 节点查询返回一致的结构化位置，后续地图拓扑可以直接读取；本轮不实现拓扑大屏。

## 当前问题

- 免费公共地图与解析服务可能暂时不可达；界面必须保留手动输入，并支持部署时替换服务上游。
- 本轮未获新的测试授权，运行结果和完整回归保持待测。

## 本轮已实现

- 新增 `000016` 迁移与独立节点定位表，两套节点列表和属性保存入口接入统一数据结构。
- 新增共享地图选点编辑器，覆盖国家、省州/地区、城市、区县、WGS84 经纬度及清除定位；节点详情、卡片和资产摘要展示已保存位置。
- 默认 OSM 底图和 Photon 解析按需加载，支持服务端环境变量替换，失败后可手工保存。
- 源码审阅中补齐输入框未失焦时的旧请求隔离，以及解析期间暂缓保存，避免新坐标搭配旧地址提交。
- 测试、构建、类型检查、lint、浏览器运行验证与手动 CI 均未执行，详见本轮记录。
