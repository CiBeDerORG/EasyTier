### 源码审阅发现与处理

| 发现 | 本轮处理 |
| --- | --- |
| 普通属性接口使用普通可选字段会合并“省略”和“显式 null” | 使用保留三态的反序列化适配，省略不清空已有定位 |
| 数字输入框在失焦前未更新模型，可能接受旧地址响应 | `input` 和 `focus` 即使尚未提交数值也使旧解析失效 |
| 选点后立即保存可能提交新坐标和旧地址 | 编辑组件同步上报解析等待状态，包含 550 ms 防抖；两处按钮和提交函数均暂缓保存 |
| 解析结果可能含存储层拒绝的控制字符 | 回填前过滤控制字符、trim、截取最多 128 个字符 |
| 429 冷却若固定最大 300 秒会早于更长的服务端指示重试 | 尊重数值形式 `Retry-After`，使用经过时间比较避免长时间加法溢出 |
| 自定义底图如果沿用默认署名会标注错误来源 | 模板与署名一起校验，无效配置整组回退到默认 OSM |

上述结论来自源码阅读，修正后的运行行为仍待验证。
