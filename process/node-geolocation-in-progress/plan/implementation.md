# 节点地理定位实现计划

## 存储和节点接口

- 新增 `node_geo_locations` 表，以 `(owner_user_id, machine_id)` 唯一关联节点，并级联清理已删除节点的数据。
- 与 `devices` 的 IP 观察字段和原安装位置分离；不改动节点心跳或 IP 地理归属解析逻辑。
- 后端共享字段规范化、坐标成对及范围校验；在现有属性写入事务中保存或删除定位。
- 两处属性接口保留“省略、清空、设置”的三态，旧调用不因缺少新字段而清空位置。
- 资产节点列表联表读取；普通节点列表按账号批量读取并合并，避免每节点额外查询。

## 地图配置与地址解析

- 在现有登录认证路由层提供地图配置和反向地址解析接口，服务实例在服务器启动时创建并复用。
- 默认 Photon 端点固定在服务端；通过环境变量可切换为 Photon 兼容服务，显式空配置可禁用自动解析。
- 校验 WGS84 坐标和语言白名单；只使用行政区字段，不采用响应里的几何坐标。
- 限制上游频率与同时在途请求，缓存成功结果；超时、无结果、服务忙和禁用状态通过明确错误响应反馈。
- 不读取节点数据、不持有节点写入锁、不转发登录凭据，也不把坐标或带凭据上游 URL 写入日志。

## 前端

- 新增共享位置编辑器，支持文本、数字、清除定位及懒加载地图选点。
- Leaflet 及 CSS 随前端依赖打包，不在运行时从第三方 CDN 下载脚本。
- 默认地图中心仅影响视图，不自动赋值；选点使用标记提示，手填坐标可以定位并解析。
- 地图显示服务端配置的署名，组件卸载时释放地图和事件；弹窗尺寸变化后刷新地图布局。
- 解析防抖、请求序号和草稿快照联合保护新输入；保存前校验字段并保留原表单的一次提交行为。
- 普通节点模型和资产节点模型使用同一 `geo_location`，详情展示地理位置和坐标；中英文文案一并更新。

## 部署配置

以下环境变量由 Web 后端在创建路由时读取，修改后重启后端生效，前端无需重新打包：

| 环境变量 | 未设置时 | 配置含义 |
| --- | --- | --- |
| `EASYTIER_NODE_GEOCODING_URL` | `https://photon.komoot.io/reverse` | Photon 兼容的完整反向解析端点；显式空值禁用自动解析；非法 URL 也仅禁用解析，不阻止应用启动 |
| `EASYTIER_NODE_MAP_TILE_URL` | `https://tile.openstreetmap.org/{z}/{x}/{y}.png` | 自定义 HTTP(S) 瓦片模板，须包含 `{z}`、`{x}`、`{y}`，也支持 `{s}`、`{r}` |
| `EASYTIER_NODE_MAP_ATTRIBUTION_TEXT` | `© OpenStreetMap contributors` | 自定义底图的署名纯文本，最多 512 个字符 |
| `EASYTIER_NODE_MAP_ATTRIBUTION_URL` | `https://www.openstreetmap.org/copyright` | 自定义底图的 HTTP(S) 署名链接 |

自定义底图须同时提供两项正确署名。模板或署名不合法时整组回退到默认 OSM 配置，避免为第三方底图展示错误署名。公开给浏览器的底图 URL 不能放服务端秘密；解析端点及其服务端查询参数不会出现在配置响应中。

解析端点拒绝 URL 用户名、密码和 fragment，可在服务端 query 参数中设置兼容供应商需要的选项；`lat`、`lon`、`lang` 和 `limit` 始终由解析处理器控制。默认语言 `local` 使用本地地名；还接受 `en`、`de` 和 `fr`。

单个后端进程最多一个解析在途请求，发起间隔至少一秒；成功结果按约六位小数坐标与语言缓存，最多 512 条、24 小时。请求总超时八秒，响应正文最多 256 KiB；禁用自动重试和重定向。上游返回 429 时采用数值形式的 `Retry-After`，至少冷却三十秒；缺失或不可解析时也冷却三十秒。客户端仅由用户再次操作重试，不自动循环请求。

若多副本共享同一公共解析服务，部署者还应在共同出口处控制总用量，或配置自托管/其他允许该用量的兼容服务；本轮进程内缓存与限速不共享跨副本状态。
