# 整合计划

1. 拉取远端节点属性分支，记录双方提交和共同基点，在新的整合分支合并。
2. 并行解决节点列表、节点详情和管理页冲突；主代理处理控制台、API 导入及迁移注册。
3. 将旧空白拓扑路由转向可用地图，令地图自动请求遵从新增全局自动刷新偏好。
4. 独立审查双侧功能和权限；更新已落后于节点分支生产契约的浏览器 fixture。
5. 验证依赖锁、前端库与应用构建、逻辑与浏览器回归、后端及迁移兼容；记录实际结果后创建中文合并提交。
6. 按用户后续要求，为新分支启用独立镜像标签，推送后跟踪远端构建、容器启动测试及 GHCR 发布，再独立匿名拉取核对源码版本、平台和前端资源。

唯一写入分工：节点列表、节点详情/管理、地图轮询、浏览器测试、后端验证分别由独立代理负责；主代理处理余下冲突、依赖、构建和本报告；审查代理只读。
