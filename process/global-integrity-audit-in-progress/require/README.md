# 范围和验收口径

- 检查 EasyTier 控制台当前业务：登录/账号、节点与绑定、服务管理/导航/公开、地图、部署 Agent、OpenWrt 发现、自动化手机会话与有限脚本。
- 对照需求、前端入口、后端路由、数据库、执行器和部署材料，区别实际缺陷、需求差距、交付缺口与尚未验证的实机边界。
- 完整执行现有应用测试，并对只测 mock、未覆盖真实依赖/进程边界的路径增加隔离验证。不得把历史记录当作本轮结果。
- 不连接未授权真实设备、不安装真实业务应用、不改生产数据。关联 deploy 工作区已有未提交内容只读检查和构建测试。
- 本轮以找问题和留下复现证据为目标，不擅自改写产品范围或批量修复业务行为。
