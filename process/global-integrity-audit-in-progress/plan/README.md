# 检查计划

1. 固定基线，审阅各需求、完成记录和实际测试覆盖。
2. 并行运行 Rust 应用测试、前端完整构建与单元测试、Go Agent 竞态检测/交叉编译、Python 执行器回归。
3. 顺序执行全部模拟浏览器套件，运行当前二进制的隔离 API 与跨仓库 Agent 联调。
4. 验证执行器固定依赖安装与真实 HTTP 契约，核对脚本、视频、回调、发现同步、服务公开及部署接线。
5. 逐项登记严重度、触发条件、代码位置、复现结果和修复方向；需产品决策的事项中途询问。
6. 汇总覆盖矩阵、失败与未执行项；不以测试数量代替完整性结论。

负责人：Codex。独立命令并行，源码审阅和共享环境操作顺序执行。
