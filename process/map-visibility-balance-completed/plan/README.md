# 实现与验证范围

主代理独占组件、现有尺寸断言及文档修改；只读复核代理查看上轮截图与代码并提供可辨识度建议；浏览器代理负责既有回归执行及流量场景扩展。本轮不新增与外观实现重复的测试。

实现：节点核心 8/10 px，带轮廓后的直径约 14/16 px；线路主线为 2/2.5/3.2 px，分别对应普通、关联选中节点、直接选中，并使用 4.4/5/5.8 px 深色底描边。柔光仅用于选中线路和小范围节点轮廓；过期线路保持灰色虚线。图例颜色同步。

描边复核发现底层 Canvas 粒子会被新 SVG 描边遮挡，因此将原流量粒子投影到 SVG 线路上方，复用原曲线与真实速率条件，逐帧直接更新元素位置，避免逐帧更新 Vue 列表。暂停、减弱动画、球面遮挡和视口裁剪均保留。

验证：前端构建，现有深度缩放、邻近线路点击及桌面/手机地图视觉用例；扩展原运行实例用例验证真实采样差分后的粒子可见与移动、暂停/恢复、减弱动画及过期状态；截图核对地球纹理、浅色陆地及密集节点处的轮廓、线条层级和遮挡。
