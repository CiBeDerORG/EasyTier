# 网络节点与设备列表界面整理

日期：2026-10-24。
基础：`CiBeDerORG/EasyTier`，`feat/node-attributes-main`，`db32036437fdbc1d4f5a081222b4490c7be1d1ec`。

## 本轮范围

用户提出六项明确修改，第七项留空，不扩展未说明的需求。

1. 节点列表的位置列改读 `geo_location`，新增设备型号列。表格、卡片、移动端同步展示；仅有坐标时展示坐标，未设置时不拿连接 IP 归属地冒充。
2. 主机名旁按已保存的 `is_public_server` 展示“公网”标识。节点元数据和设备计数使用一次同账号查询，不在每秒心跳轮询中增加资产请求。
3. 移除旧地点输入、卡片及详情展示。后端旧字段暂保留兼容，属性写入时仅发送 `site_location: null` 退役它；结构化地理位置继续保存。
4. 设备列表页移除节点基本资料区、节点编辑/删除按钮及对应无入口表单代码，保留节点选择、筛选和设备/服务管理。
5. “节点详情”显示名称改为“设备列表”，沿用 `nodeAssets` 路由及 URL，不改页面用途或存量链接。
6. Web 控制台统一处理弹窗蒙层点击，通过 PrimeVue Pass Through 发出原有关闭事件。已有原生蒙层关闭沿用原生行为；父子弹窗、保存禁用关闭及拖动从内部松手不被全局处理误关。

公网服务器设置随节点编辑入口收敛到网络节点列表的属性弹窗，避免删除设备列表页的节点表单后丢失角色设置入口。
